# Sida 라이노 플러그인

라이노 8(Windows)용 플러그인입니다. 앱 패키지(`sida/`)에는 들어가지 않습니다(`relay/`, `collector/`와 같은 방식). 하는 일은 운반과 캡처뿐입니다.

- `SidaPull`: 이 문서의 Sida 프로젝트 제도판(대지 경계, 매스안, 주변 3D, 지형)을 `Sida` 레이어 아래로 가져옵니다. 전에 가져온 개체(사용자 문자열 `sida.id`가 있는 것)는 바꾸고, 설계자가 만든 개체는 건드리지 않습니다. 가져온 뒤 설계자가 옮기거나 고친 개체도 설계자의 것으로 보고 그대로 둡니다. 주변·대지 경계 레이어에는 의미를 미리 붙여 둡니다. 좌표는 Sida 내보내기와 같은 틀(원점 대지 가운데, m)을 문서 단위로 바꿔 둡니다.
- `SidaPush`: 건물 의미를 준 레이어의 보이는 입체마다 라이노가 잰 값(부피, 바닥 단면 외곽선(중정은 뚫린 곳으로), 층고마다 자른 층별 면적, 높이)과 평면·투시 뷰 캡처를 스냅샷으로 Sida에 보냅니다. 수치(연면적·건폐율·용적률)는 Sida가 계산해 돌려줍니다(`docs/rhino-api.md`).
- `SidaDraw`: 지금 모델을 Sida로 보낸 뒤, Sida가 그 스냅샷으로 그린 다이어그램(프로그램 매스, 층별 분해, 층별 면적, 대지 배치도, 법정 수치 비교)의 그리기 지시를 받아 `Sida 다이어그램` 레이어 아래에 라이노 도형(입체, 해치, 선, 글자)으로 만듭니다(`Drawer.cs`). 무엇을 어디에 그릴지는 Sida가 정하고 플러그인은 따르기만 합니다. 그림은 모델의 동쪽 옆에 놓이고 종류마다 한 묶음(그룹)입니다. 다시 그리면 전에 그린 것을 바꾸되, 설계자가 고친 도형은 그대로 두고, 설계자가 그림을 옮겨 두었으면 그 자리에 다시 그립니다. 이 레이어는 수치에서 빠집니다(의미 `ignore`). 패널의 "라이노에 그리기"가 이 명령입니다.
- `SidaPanel`: 패널. Sida의 라이노용 화면(`webui/app/rhino.html`)을 웹 뷰로 보여 줍니다. 모델링하는 동안 건폐율·용적률·연면적이 한도와 함께 바로 바뀌고, 프로젝트 고르기, 레이어마다 의미·층고, 다이어그램 고르기와 "라이노에 그리기", 가져오기·보내기, "저장할 때마다 보내기"가 여기 있습니다. "Sida에게 묻기" 탭에서는 지금 모델을 두고 Sida(Conductor)에게 묻습니다: 모델의 수치와 라이노에서 고른 개체가 질문과 함께 가므로 "이거 연면적 얼마야?"처럼 물을 수 있고, 대화는 Sida의 그 프로젝트에 남습니다. 처음 열면 레이어 패널 옆 탭으로 붙습니다. Sida가 꺼져 있으면 그 안내만 보이고, 켜면 저절로 이어집니다.
- `SidaBrowser`: 같은 화면을 기본 브라우저에서 엽니다(화면이 둘일 때, 또는 웹 뷰가 안 뜨는 PC).

패널 화면은 라이노와 직접 말하지 않습니다. 플러그인(`LiveLink.cs`)이 문서나 고른 개체가 바뀔 때마다 스냅샷(뷰·메시 없이)과 고른 개체의 id를 Sida에 알리고 0.5초마다 패널이 부탁한 일을 물어 가며, 화면은 Sida에게서 읽습니다(`docs/rhino-api.md`의 "실시간"). 바뀐 개체만 다시 재므로 큰 문서에서도 가볍습니다. 패널에서 누른 "Sida에서 가져오기"는 배경에서 내려받고(처음에는 30초 넘게 걸릴 수 있고 그동안 라이노를 그대로 쓸 수 있음) 다 받은 뒤에 문서에 넣으며, 지금 하는 일은 패널에 "가져오는 중…"처럼 보입니다. 통신은 모두 배경 스레드에서, 문서를 만지는 일은 명령 사이에 라이노 UI 스레드에서 합니다.

레이어 의미와 층고는 레이어의 사용자 문자열(`sida.meaning`, `sida.floor_height`)에, 프로젝트와 자동 보내기는 문서 문자열(`sida.project`, `sida.autosync`)에 저장되어 파일을 다시 열어도 남습니다.

v1에서 아직 안 되는 것(설계상): 바닥 외곽선은 가장 낮은 점 5cm 위 단면이라 위층이 튀어나온 부분은 건축면적에서 빠집니다. 층고를 정하지 않은 레이어의 개체는 층별 면적이 없어 연면적에서 빠지고 Sida가 그렇게 알려 줍니다. 블록(인스턴스)은 열어 보지 않습니다. 캡처는 평면(Top)·투시(Perspective) 뷰 그대로입니다.

## 빌드

필요한 것: .NET SDK 8. RhinoCommon은 NuGet에서 받으므로 빌드에 라이노도 Windows도 필요하지 않습니다(대상은 `net7.0`, Linux에서도 빌드됩니다). PR마다 GitHub Actions(`rhino-plugin.yml`)가 빌드해 `.rhp`를 결과물로 올립니다.

```powershell
cd rhino-plugin\SidaRhino
dotnet build -c Release
# → bin\Release\net7.0\SidaRhino.rhp
```

라이노에서 시험: `PlugInManager` → 설치 → 위 `.rhp`. 또는 라이노 명령창에서 `_-PlugInManager _Load`로 경로를 줍니다. 그 뒤 `SidaPanel`.

Sida 앱이 같은 PC에서 `run.bat`으로 떠 있어야 합니다(`127.0.0.1:8765`). 다른 주소면 환경 변수 `SIDA_URL`.

## 나눠 줄 파일 만들기 (CBT 배포)

```powershell
dotnet build rhino-plugin\SidaRhino\SidaRhino.csproj -c Release
python scripts\package_rhino_plugin.py
# → rhino-plugin\dist\Sida-Rhino-0.1.0.zip        참가자에게 주는 묶음
# → rhino-plugin\dist\sida-0.1.0-rh8_0-win.yak    라이노 패키지
```

Yak.exe는 쓰지 않습니다(없거나 고장 난 PC가 있고, 패키지는 zip일 뿐입니다). 버전은 `manifest.yml`의 `version` 하나에서 읽고, `SidaRhino.csproj`의 `<Version>`과 같아야 합니다(테스트가 확인). PR마다 GitHub Actions(`rhino-plugin.yml`)가 같은 두 파일을 만들어 결과물로 올립니다.

- **`Sida-Rhino-<버전>.zip`**: `SidaRhino.rhp`, `manifest.yml`, `install.bat`, `uninstall.bat`, `설치 안내.txt`([`INSTALL.ko.txt`](INSTALL.ko.txt)). 압축을 풀고 라이노를 끈 채 `install.bat`을 더블클릭하면 라이노 패키지 관리자가 두는 자리(`%APPDATA%\McNeel\Rhinoceros\packages\8.0\sida\<버전>\`)에 파일을 넣고, `sida\manifest.txt`에 버전을 적고(이 파일이 없으면 라이노가 시작할 때 폴더를 지웁니다), 내려받은 파일의 차단을 풉니다. 전에 설치한 버전은 지우고 넣습니다.
- **`.yak`**: `manifest.yml`과 `.rhp`가 든 zip입니다. `yak install <파일>`이 되는 PC나 패키지 서버에 올릴 때 씁니다.

## 한 사이클 시험 순서 (무교동 45)

1. Sida에서 대지 조회, 매스안 하나(블록 2개).
2. 라이노 8 빈 문서(단위 m 또는 mm) → `SidaPanel` → 프로젝트 고르기 → "Sida에서 가져오기". 대지 경계·매스·주변 3D가 같은 자리에 들어오는지(처음에는 30초쯤 걸릴 수 있음).
3. 블록 하나를 밀고 층을 올리고, 새 레이어에 곡선 매스를 하나 더. 패널에서 레이어 의미(주거·상업)와 층고를 지정.
4. 매스를 고칠 때마다 패널의 건폐율·용적률·연면적이 1초쯤 안에 바뀌고 손계산과 같은지. "Sida로 보내기": Sida 제도판에 "라이노 작업" 종이가 생기는지.
5. 같은 파일에서 다시 "Sida에서 가져오기": 설계자 레이어가 그대로인지.
6. 패널의 "라이노에 그리기": `Sida 다이어그램` 레이어에 고른 그림이 모델 옆에 생기는지, 다시 눌러도 겹쳐 쌓이지 않는지. Sida 제도판의 "라이노 작업" 종이 속성에 같은 그림이 보이고 SVG·PNG로 내려받아지는지.
7. "저장할 때마다 보내기"를 켜고 저장: 제도판의 종이가 새 스냅샷으로 바뀌는지.
8. 패널의 "Sida에게 묻기": 매스 하나를 고르고 "이거 연면적 얼마야?"를 물어, 답이 패널의 수치와 맞는지. Sida 화면의 "이전 대화"에 같은 대화가 있는지.
9. Sida의 발표 편집자 화면 "발표자료" 탭: 슬라이드에 방금 보낸 모델의 다이어그램·캡처·수치가 들어 있는지. "PowerPoint 받기"로 받은 파일이 파워포인트에서 고치라는 말 없이 열리고, 수치 표의 숫자가 4번의 패널 숫자와 같은지, 다이어그램을 눌러 도형 색을 바꿀 수 있는지. "PDF 받기"의 한글이 깨지지 않는지.
10. Sida를 끄기: 패널에 한국어 안내가 나오고 라이노가 멈추지 않는지. 다시 켜면 패널이 저절로 이어지는지.

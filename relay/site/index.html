건축 학생을 위한 설계 조수

근거 있는 대지·법규 분석과, AI 전문가가 둘러앉은 제도판

대지와 법규는 정부 자료에서 가져온 값으로만 정리하고, 열 명의 전문가가 각자의 관점에서 설계 고민을 함께 읽습니다. 설계는 여전히 내가 합니다. Sida는 그 옆에서 근거를 챙기는 조수입니다.

설치 방법 보기 접속 키 신청

시다는 한국 건축 학계에서 후배나 조수·보조를 부르는 말입니다.

01

무엇을 하나요

내 노트북에서 도는 웹 앱입니다. 브라우저로 열어 씁니다.

근거 있는 대지·법규

주소나 지번으로 지목, 면적, 용도지역, 건축물대장을 정부 자료에서 바로 가져옵니다. 가져오지 못한 값은 지어내지 않고 “미확인”으로 남깁니다.

조문과 함께 보는 수치

조례의 건폐율·용적률은 정해진 규칙으로만 읽고, 항상 원문 조문 줄을 같이 보여 줍니다. 하나로 읽히지 않으면 숫자를 내지 않습니다.

전문가 제도판

대지·프로그램·법규·사례·개념·공간·시스템·비평·표현·발표, 열 명의 전문가가 각자 문서를 쓰고 Conductor가 조건과 충돌, 지금 정할 것을 정리합니다.

Sida는 최종 설계를 대신하지 않습니다. 결과물은 생각을 정리하는 구조화된 문서와 제도판입니다.

02

설치 방법

Windows 기준으로 10분이면 됩니다. Docker나 별도 빌드는 필요 없습니다.

  1. Python 3.10 이상 설치

    python.org에서 받아 설치합니다. 설치 첫 화면에서 “Add python.exe to PATH”를 꼭 체크하세요.

  2. Sida 받기

    지금은 비공개로 시험하고 있습니다. 써 보고 싶다면 jhp503@gmail.com로 메일을 보내 주세요. 받는 방법을 안내해 드립니다. 받은 폴더는 원하는 곳에 압축을 풀어 둡니다.

  3. run.bat 더블클릭

    처음 한 번은 필요한 것을 설치하느라 몇 분 걸립니다. 끝나면 브라우저에 http://127.0.0.1:8765가 열립니다.

  4. 모델 연결

    설정 창에서 ChatGPT로 로그인하면 내 ChatGPT 구독으로 바로 쓸 수 있습니다. OpenRouter 키를 넣어 쓰는 방법도 있습니다.

  5. Sida 키 받기

    정부 API 키가 없어도 Sida 접속 키가 있으면 대지 조회와 법령 검색을 쓸 수 있습니다. 아래 안내를 보세요.

macOS · Linux에서 설치하기

Python 3.10 이상이 있으면 터미널에서 아래처럼 실행합니다.

cd Sida
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
python webapp.py
03

접속 키 신청

정부 API 키를 직접 받지 않아도, Sida 자료 서버를 거쳐 대지 조회·법령 검색·3D 지도를 쓸 수 있습니다.

  1. 앱에서 요청

    Sida 설정 창의 Sida 키 받기에 이름(소속)과 연락처(선택)를 적고 키 요청을 누릅니다.

  2. 개발자에게 메일로 알리기

    요청은 개발자가 하나씩 확인해 승인합니다. 요청한 뒤 jhp503@gmail.com로 키를 신청했다고 메일을 보내 주세요. 앱에 적은 이름(소속)을 같이 적어 주시면 빨리 찾을 수 있습니다.

  3. 자동으로 받기

    승인되면 앱을 켜거나 설정 창을 열 때 키가 저절로 저장됩니다.

한 사람에 키 하나잃어버리면 폐기하고 새로 만듭니다.
하루 3,000번까지한국 시간 자정에 다시 셉니다.
정부 키는 서버에만앱과 내 PC에는 정부 키가 들어가지 않습니다.
04

개인정보 처리방침

초안 · 시행일은 정해지는 대로 적습니다

받는 정보

  • 키를 요청할 때 적은 이름(소속)과 연락처(선택). 키를 승인하는 개발자만 봅니다.
  • 키마다 날짜·서비스별 호출 수와 실패 수. 한도를 지키고 서버 상태를 보는 데만 씁니다.

남기지 않는 정보

  • 조회한 주소·지번·검색어와 정부 서비스의 응답. 중계만 하고 저장하지 않습니다.
  • 접속 키 원문. 서버에는 되돌릴 수 없는 값(SHA-256)만 둡니다.
  • 요청별 접속 기록(액세스 로그).

내 PC에 남는 것

브리프, 전문가 문서, 프로젝트 파일은 모두 내 PC의 ~/Sida 폴더에 있습니다. 이 서버로 보내지 않습니다. 앱의 사용 기록 보내기는 기본으로 꺼져 있고, 켠 경우에도 브리프·문서·오류 원문은 보내지 않습니다.

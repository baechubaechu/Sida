# 법규 볼륨 (정북일조 껍데기와 참고 매스)

제도판 도구 막대의 매스 묶음에 있는 "법규 볼륨" 버튼(명령 `envelope`)이 쓰는 자료입니다. 대지에 정북일조 높이 제한과 건폐율·용적률을 적용해 지을 수 있는 볼륨(층마다 영역)을 만들고, 그 안에 들어가는 참고 매스 두 가지를 냅니다. 로직은 `sida/experts/site/envelope.py`, 건축 조례 읽기는 `sida/experts/regulation/ordinance.py`(`sunlight_lookup`, `sunlight_rule`), 경로는 `sida/experts/site/api.py`, 화면은 `webui/app/table-envelope.js`입니다.

최종 설계나 인허가 검토를 대신하지 않습니다. 대지 안의 공지·건축선·고도지구·공동주택 채광은 아직 넣지 않았고, 카드에 "확인 필요"로 보입니다.

## API

| 메서드·경로 | 요청 | 응답 |
|---|---|---|
| `GET /api/projects/{name}/site/envelope?floor_height=3` | `floor_height`(m, 2~10, 선택): 층을 세는 층높이. 안 주면 주거지역 3m, 그 밖은 제도판 기본 층높이 | 아래 표. 대지 사실이 없으면 `404`, 대지 경계가 없으면 `400`, 층높이가 범위 밖이면 `400` |

| 키 | 뜻 |
|---|---|
| `zone`, `area_m2` | 용도지역(여러 개면 쉼표로), 대지면적 |
| `bcr`, `far`, `bcr_from`, `far_from` | 건폐율·용적률(%)과 출처(`조례`·`법정`). 대지 사실의 값을 그대로 씀(조례 우선) |
| `floor_height` | 층높이(m) |
| `frame` | 제도판의 동 좌표계(`{x, y, angle}`), 매스 동의 `u, v`가 이 좌표계 |
| `levels` | `[{z, rings}]`: 높이 `z`(m)까지 올라갈 수 있는 영역. `rings`는 제도판 좌표(x 동쪽, y 북쪽, m)의 바깥 고리. 정북일조가 없으면 `[]` |
| `max_height_m` | 정북일조로 가장 높이 올라가는 곳의 높이. 제한이 없는 곳이 있으면 `null` |
| `full_floor_area_m2` | 볼륨을 층마다 다 채웠을 때의 연면적(용적률 무시) |
| `grid` | 동이 볼륨을 넘는지 화면에서 재는 격자: `{u0, v0, step, h}`. `h[j][i]`는 칸(u0 + i·step, v0 + j·step에서 한 변 step)이 올라갈 수 있는 높이, `null`은 대지 밖, `-1`은 제한 없음. 칸이 많으면 묶은 칸 안의 가장 낮은 값 |
| `schemes` | 참고 매스 `[{name, blocks, floor_height, footprint_m2, floor_area_m2, height_m}]`: "넓게 낮게"(건폐율만큼 깔고 층마다 줄임), "남쪽 탑형"(남쪽에 좁게, 용적률을 채우는 가장 작은 바닥). `blocks`는 매스안 동과 같은 모양 |
| `lines` | 카드 줄 `[{id, status, title, value, detail, quote, source}]`. `status`: `read`(규칙으로 읽음), `check`(확인 필요), `none`(해당 없음). `quote`는 조문 원문 |
| `neighbours` | `{error, crossed}`: 북쪽 이웃 필지를 못 받았을 때의 오류, 건너편에서 잰 지목(도로·공원 등) |

## 법 기준

정북일조 거리는 건축법 제61조①(법률 제21880호, 2026-11-12 시행)에 있습니다. 높이 10m 이하 부분 1.5m, 10~17m 부분 5m, 17m 넘는 부분은 그 높이의 1/2 이상이고, 조례는 이 범위에서 거리를 정합니다. 같은 날 시행령 제86조①은 삭제됐고, 예외는 시행령 제86조②(1. 북쪽 이웃이 전용·일반주거지역이 아님, 2. 지구단위계획구역 등의 20m 도로, 3. 건축협정구역)로 옮겨졌습니다. 부칙 제4조에 따라 2026-11-12 이후 건축허가 신청·건축신고분부터 적용됩니다.

이 수치와 원문은 `data/site_rules.yaml`의 `north_sunlight`에 있고, 계산은 이 파일만 읽습니다(실행할 때 법령을 받아 오지 않음). 법이 바뀌면 law.go.kr 현행 원문과 대조해 파일을 고치고 `verified` 날짜를 바꿉니다. 지역별 조례 거리는 대지를 처음 계산할 때 한 번 받아 정해진 패턴으로만 읽고 프로젝트에 저장합니다.

## 계산

1. 대지를 동 좌표계의 격자(0.5m부터, 칸이 4만 개를 넘지 않게)로 나눕니다.
2. 칸마다 정북 방향으로 대지 경계까지 잽니다. 경계 너머 필지의 지목이 도로·철도용지·하천·공원(`data/site_rules.yaml`의 `across_marks`)이면 그 필지를 건너 다음 경계에서 잽니다(시행령 제86조⑥). 구거·유지·제방은 건너지 않고 줄에 "확인"으로 남깁니다.
3. 경계 너머 필지가 주거지역이 아니면 그 칸은 정북일조를 적용하지 않습니다(건축법 제61조① 단서, 시행령 제86조②1). 용도지역은 토지이용계획에서 필지마다 받아 한 시간 동안 메모리에만 둡니다. 모르는 경우는 적용합니다(안전한 쪽).
4. 거리 → 높이는 대지 시·군·구(없으면 시·도)의 건축 조례에서 정북일조 조문 첫 항을 규칙으로 읽습니다. 예: 서울특별시 건축 조례 제35조① → 1.5m 띄우면 10m, 5m 띄우면 17m, 그 위는 높이의 1/2. 못 읽거나 읽은 거리가 법의 범위보다 짧으면 법의 최소 거리로 계산하고 "확인 필요"라고 씁니다. 읽은 조문은 대지 사실(`building_ordinance`)에 저장해 다시 조회하지 않습니다. 연결 실패는 저장하지 않고 다음에 다시 시도합니다.
5. 층마다 올라갈 수 있는 칸을 모아 `levels`를 만들고, 참고 매스는 층마다 아래 층 안에서 가장 큰 직사각형을 찾아 쌓은 뒤 건폐율·용적률에 맞게 자릅니다.

이웃 필지 모양(연속지적도)은 요청마다 받아 계산에만 쓰고 저장하지 않습니다(브이월드 이용 조건).

## 화면

- 버튼을 누르면 볼륨이 반투명 층으로 서고, 왼쪽 카드에 수치, 참고 매스, 규칙 줄(누르면 원문)이 보입니다.
- "매스안으로 놓기"는 참고 매스를 새 매스안 종이로 만들어 3D로 세웁니다. 이후는 보통 매스안처럼 고칩니다.
- 볼륨이 켜져 있는 동안 3D로 선 매스안의 동이 볼륨보다 높으면 테두리가 대지 선 색이 되고 층 표시에 "볼륨 넘음"이 붙으며, 카드에 동마다 넘는 높이가 나옵니다(`board-model.js`의 `envelopeOver`).

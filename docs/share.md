# 공유 (보기 링크와 댓글)

설계자가 제도판의 지금 모습을 국내 서버(`relay/`)에 올리면, 링크를 받은 사람(교수, 팀원)은 Sida 없이 브라우저로 3D 매스와 대지 카드를 보고 댓글을 남깁니다. 댓글은 설계자의 Sida로 돌아와 제도판에 핀으로 꽂힙니다. 1단계(2026-11-17)는 업로드·보기 화면·댓글까지이고, 답글 알림(원하는 사람만 Google 로그인)은 2단계 맨 앞입니다.

## 정한 것

- **AI 대화는 올리지 않습니다.** Conductor·전문가 대화와 전문가 결과는 본인만 봅니다.
- 보는 사람은 **링크로만** 구분합니다. 댓글을 쓸 때 이름만 적습니다(계정 없음).
- 링크는 두 개입니다: 댓글 링크(보기+댓글)와 보기 링크(보기만). 설계자는 언제든 새 링크로 바꿀 수 있고(옛 링크는 바로 끊김), 댓글을 닫을 수 있습니다.
- 서버는 마지막 업로드부터 **30일** 보관합니다. 한 공유 20MB, 한 사람(키) 100MB, 동시에 공유 10개, **2주에 새 공유 10개**, 하루 업로드(새 판 포함) 20번. 모두 서버 환경 변수로 바꿉니다(`relay/README.md`의 "공유").
- 새 판을 올리면 링크는 그대로이고 판 번호가 하나 오릅니다. 자리가 모자라면 오래된 판부터 지웁니다. 댓글은 어느 판에 달렸는지 기억합니다.
- 공유를 끄면 서버의 스냅샷과 댓글이 지워지고, 댓글은 설계자의 프로젝트(`share.json`)에 남습니다.

## 무엇이 올라가나

`sida/share.py`의 `build`가 제도판(`board.view`)에서 만듭니다. zip 하나에 `snapshot.json`과 `photos/<id>.jpg|png`만 들어갑니다.

- **보이는 레이어**의 종이 중 대지, 매스안, 트레이싱, 메모, 사진. 숨긴 레이어의 것은 빠집니다.
- 매스안 수치(건축면적·연면적·건폐율·용적률·높이)는 서버가 계산한 값을 그대로 넣습니다. 보기 화면은 계산하지 않습니다.
- 대지 카드의 줄과 "이 대지에 걸리는 것", 대지 도면의 범위·좌표계·필지 번호·주소·면적.
- 사진은 긴 변 2000px로 줄입니다(투명하면 PNG, 아니면 JPEG). 공유 창에서 사진을 빼고 올릴 수도 있습니다.
- 빠지는 것: 전문가 결과, 라이노 작업, 단면, PDF, 대화. 공유 창이 몇 개가 빠지는지 알려 줍니다.
- **필지 경계선은 저장하지 않습니다**(브이월드 이용약관 제19조). 보기 화면이 열릴 때 서버가 필지 번호로 브이월드에 물어 그때그때 보여 줍니다(`/s/<링크>/parcels`).

## 앱 (설계자)

- 제도판 머리의 "공유" 버튼이 옆 창(`webui/app/share.js`)을 엽니다: 올라가는 것, 링크 두 개(복사), 댓글, 사용량. 새 댓글이 있으면 버튼에 "새 댓글 N"이 붙습니다.
- 댓글에서 답글, 해결, 삭제(두 번 눌러 확인), 위치 보기(제도판의 핀으로), "Conductor에게 묻기"(그 매스안을 고르고 명령창에 질문을 넣음)를 합니다.
- 제도판의 댓글 핀은 `webui/app/table-comments.js`입니다. 안 읽은 것은 주황, 해결한 것은 회색입니다.
- 공유하려면 Sida 키(`SIDA_RELAY_TOKEN`)가 있어야 합니다. 팀이 키 하나를 같이 쓰면 그 팀의 공유는 모두 한 사람으로 세어 한도를 같이 씁니다.

| 경로 (`/api/projects/{name}/share`) | 하는 일 |
|---|---|
| `GET ""` | 올라갈 것(`papers`, `left_out`), 지금 공유 상태(`share`), 키가 있는지(`has_key`) |
| `POST ""` `{photos, by}` | 처음이면 공유를 만들고, 이미 있으면 새 판을 올림. `{share, made}` |
| `PATCH ""` `{comments_open?, new_links?}` | 댓글 열기·닫기, 새 링크 |
| `DELETE ""` | 공유 끄기(서버에서 지움, 댓글은 여기에 남음) |
| `GET /comments?refresh=1` | 서버에서 댓글을 받아 옴 `{comments, unread, seen, on}`. 서버에 닿지 못하면 남겨 둔 것과 `stale` |
| `POST /comments` `{parent, text}` | 설계자 답글 |
| `PATCH /comments/{id}` `{resolved}` | 해결 표시 |
| `DELETE /comments/{id}` | 지우기(공유가 꺼져 있으면 이 PC에서만) |
| `PUT /comments/seen` `{ids}` | 읽음 표시 |

오류는 `{"detail": {"code", "message"}}`이고, `code`는 `no_key`, `gone`, 한도 이름(`share_bytes`, `new_shares` 등) 중 하나입니다.

## 보기 화면 (보는 사람)

서버가 `/s/<링크>`에서 `webui/app/share.html`을 내줍니다(`share-view.js`, `share.css`, 도우미는 `share-model.js`). 앱의 제도판을 다시 쓰지 않는 가벼운 화면입니다.

- 위: 프로젝트 이름, 올린 사람과 날짜, 판 고르기.
- 가운데: 매스안 탭, 수치 줄, 3D(평평한 땅 위의 필지선과 매스, 끌어 돌리기·Shift나 오른쪽 끌기로 옮기기·휠로 확대).
- 옆: 댓글, 대지, 메모·사진. 댓글 링크면 "댓글 놓기"로 매스나 땅을 찍어 그 자리에 댓글을 답니다.
- 주변 건물(브이월드 3D 단색)은 아직 없습니다. 다음 단계입니다.
- 브라우저 저장소를 쓰지 않습니다. 검색 엔진에 잡히지 않게 `noindex`, 다른 사이트에 링크가 새지 않게 `no-referrer`를 붙입니다.

## 서버

경로, 한도, 설치는 [`relay/README.md`](../relay/README.md)의 "공유"에 있습니다. 서버 코드는 `relay/shares.py`(저장·한도·댓글)와 `relay/app.py`(경로)이고, 테스트는 `tests/relay/test_shares.py`, 앱 쪽은 `tests/test_share.py`(실제 중계 서버를 메모리에 띄워 끝까지 확인)입니다.

# 모형 바탕 (레이저 커팅)

대지 주변 땅을 등고선 층으로 잘라 레이저 커팅 파일로 만들고, 사용자의 재료 판 안에 최대한 빽빽하게 배열합니다. 지금은 땅만 하고, 땅은 **예시 지형**(무작위, `--seed`)입니다. 실제 지형 데이터와 주변 건물은 다음 단계입니다. 코드는 `sida/model_base/`, 실행은 `scripts/model_base_terrain.py`입니다(화면과 API는 아직 없음).

```bash
python scripts/model_base_terrain.py --sheet 600x400 --thickness 3 --scale 500 --area 240x180 --out output/model_base
```

| 옵션 | 뜻 | 기본 |
|---|---|---|
| `--sheet` | 재료 판 크기 mm (가로x세로) | 600x400 |
| `--thickness` | 재료 두께 mm. 등고 간격 = 두께 × 축척 / 1000 m (3 mm, 1:500 → 1.5 m) | 3 |
| `--scale` | 모형 축척 1:N | 500 |
| `--area` | 모형에 담을 땅 m (동서x남북) | 240x180 |
| `--hollow` | 다음 층에 가려지는 속을 비우고 남길 테두리 폭 mm. 0이면 속이 찬 층 | 8 |
| `--chunk` | 비운 층의 가는 테두리를 나눌 크기 mm. 주지 않으면 여러 크기를 시험해 판이 가장 적게 드는 것, 그중 조각이 가장 적은 것을 고름. 0이면 나누지 않음 | 자동 |
| `--gap`, `--margin` | 조각 사이 간격, 판 가장자리 여백 mm | 2, 5 |
| `--rotations`, `--res` | 조각마다 시험할 방향 수, 배열 격자 mm(작을수록 빽빽하고 느림) | 8, 1 |

## 나오는 파일

- `sheet-N.svg`, `sheet-N.dxf`: 레이저용, mm. **빨강 = 자르기, 파랑 = 새기기**(DXF는 `CUT`·`ENGRAVE` 레이어). 레이저실마다 색 규칙이 다르면 레이저 프로그램에서 색을 바꾸거나 `sheet_svg(..., colors=)`를 씁니다.
- `sheet-N-guide.svg`: 사람이 보는 같은 판. 높이별 색, 큰 조각 이름.
- `assembly.svg`: 완성 모형을 위에서 본 조립도. 조각마다 `이름·판 번호`(예: `05A6·3`), 대지 경계(빨간 점선), 방위, 축척 막대.
- `pieces.csv`: 조각 목록(이름, 층, 등고 높이, 판, 토막 번호, 면적, 이름이 가려지는 면에 새겨졌는지).

## 조각을 알아보는 법

- 이름 `03B`: 3층(아래에서 네 번째 판), B 조각(같은 층에서 북쪽부터, 같은 줄이면 서쪽부터). 나눈 토막은 뒤에 번호가 붙음(`03B2`).
- 조각마다 이름과 **북쪽 화살표**가 새겨집니다. 이름은 되도록 다음 층에 가려지는 면에 새겨 완성 모형에는 보이지 않습니다.
- **다음 층이 놓일 선**과, 보이는 면에 걸친 **대지 경계**가 새겨져 있어 맞춰 붙이기 쉽습니다.

## 배열 방식

조각을 격자로 바꿔, 외곽이 차지하는 크기가 큰 조각부터 여러 방향으로 돌려 가며 판의 가장 아래·왼쪽 빈자리에 넣습니다(모든 자리를 FFT 상관으로 한 번에 검사). 조각의 구멍도 빈자리라서, 속을 비운 층의 구멍에 작은 조각이 들어갑니다. 판보다 큰 조각은 판 크기로 나눕니다.

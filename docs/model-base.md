# 모형 바탕 (레이저 커팅)

대지 주변 땅을 등고선 층으로 잘라 레이저 커팅 파일로 만들고, 사용자의 재료 판 안에 최대한 빽빽하게 배열합니다. 지금은 땅만 하고, 땅은 **예시 지형**(무작위, `--seed`)입니다. 실제 지형 데이터와 주변 건물은 다음 단계입니다. 코드는 `sida/model_base/`, 실행은 `scripts/model_base_terrain.py`입니다(화면과 API는 아직 없음).

```bash
python scripts/model_base_terrain.py --sheet 600x400 --thickness 3 --scale 500 --area 240x180 --out output/model_base
```

| 옵션 | 뜻 | 기본 |
|---|---|---|
| `--sheet` | 재료 판 크기 mm (가로x세로) | 600x400 |
| `--thickness` | 재료 두께 mm. 등고 간격 = 두께 × 축척 / 1000 m (3 mm, 1:500 → 1.5 m) | 3 |
| `--scale` | 모형 축척 1:N | 500 |
| `--area` | 모형에 담을 땅 m (동서x남북) | 240x180 |
| `--hollow` | 다음 층에 가려지는 속을 비우고 남길 테두리 폭 mm. 0이면 속이 찬 층 | 0 |
| `--colors` | 레이저 색, 예: `engrave=#0000FF,inner=#FF0000,outer=#00A000` | 왼쪽 예 |
| `--gap`, `--margin` | 조각 사이 간격, 판 가장자리 여백 mm | 2, 5 |
| `--rotations`, `--res` | 조각마다 시험할 방향 수, 배열 격자 mm(작을수록 빽빽하고 느림) | 8, 1 |

## 나오는 파일

- `sheet-N.svg`, `sheet-N.dxf`: 레이저용, mm. 선이 세 가지이고 레이저는 이 순서로 돌립니다: **새기기(파랑)** → **내부 커팅(빨강)**: 구멍과 구멍 속 조각의 외곽, 안쪽 것부터 → **외부 커팅(초록)**: 바깥 외곽. DXF 레이어는 `ENGRAVE`, `CUT_INNER`, `CUT_OUTER`, SVG 그룹도 같은 순서입니다. 레이저실 색 규칙이 다르면 `--colors`로 바꿉니다.
- `sheet-N-guide.svg`: 사람이 보는 같은 판. 높이별 색, 큰 조각 이름.
- `assembly.svg`: 완성 모형을 위에서 본 조립도. 조각마다 `이름·판 번호`(예: `1-05A·3`), 모듈 경계와 번호, 대지 경계(빨간 점선), 방위, 축척 막대.
- `pieces.csv`: 조각 목록(이름, 모듈, 층, 등고 높이, 판, 면적, 이름이 가려지는 면에 새겨졌는지).

## 조각을 알아보는 법

- 이름 `03B`: 3층(아래에서 네 번째 판), B 조각(같은 층에서 북쪽부터, 같은 줄이면 서쪽부터). 모듈로 나뉜 모형은 앞에 모듈 번호가 붙음(`1-03B`).
- 조각마다 이름과 **북쪽 화살표**가 새겨집니다. 이름은 되도록 다음 층에 가려지는 면에 새겨 완성 모형에는 보이지 않습니다.
- **다음 층이 놓일 선**과, 보이는 면에 걸친 **대지 경계**가 새겨져 있어 맞춰 붙이기 쉽습니다.

## 판보다 큰 모형: 모듈로 나누기

모형이 판보다 크면 **모형 전체를 반으로**(그래도 크면 4등분, 6등분…) 먼저 나눕니다. 나누는 선은 모형을 가로지르는 직선이고 모든 층이 같은 선에서 나뉘어, 판 두 장으로 만든 스터디 모형처럼 모듈을 따로 쌓아 붙입니다. 긴 변을 먼저 자르고, 모듈은 되도록 정사각형에 가깝게 합니다. 모듈이 판에 들어가므로 층 조각은 더 나누지 않습니다.

- 조각 이름 앞에 모듈 번호가 붙습니다: `1-03B` = 1번 모듈 3층 B 조각. 모듈 번호는 북서쪽부터 셉니다.
- 조립도에 모듈 경계(굵은 선)와 번호가 나옵니다.

## 구멍 속 조각과 자르는 순서

레이저는 내부 커팅 → 외부 커팅 두 번으로 자르므로, 구멍에는 **구멍 없는 조각만 한 겹** 들어갑니다(구멍 있는 조각은 다른 조각의 구멍에 들어가지 않음). 구멍은 땅이 움푹한 곳이나 `--hollow`로 속을 비운 층에서 생깁니다.

## 배열 방식

조각을 격자로 바꿔, 외곽이 차지하는 크기가 큰 조각부터 여러 방향으로 돌려 가며 판의 가장 아래·왼쪽 빈자리에 넣습니다(모든 자리를 FFT 상관으로 한 번에 검사).

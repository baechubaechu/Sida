# 모형 바탕 (레이저 커팅)

대지 주변 땅을 등고선 층으로 잘라 레이저 커팅 파일로 만들고, 사용자의 재료 판 안에 최대한 빽빽하게 배열합니다. 스크립트의 땅은 **예시 지형**(무작위, `--seed`)입니다. 화면과 API는 다음 단계입니다. 코드는 `sida/model_base/`, 실행은 `scripts/model_base_terrain.py`입니다.

## 주변 건물

`slice_terrain(..., buildings=...)`에 건물(`sida/model_base/buildings.py`의 `Building`, 제도판 좌표)을 주면 모형 위에 세웁니다. 주변 3D 결과는 `buildings_from_context(around)`로 바꿉니다. 대지 안 건물은 뺍니다.

- 높이를 아는 건물은 **바닥 모양을 판 여러 장으로 쌓아** 만듭니다. 장 수는 지붕 높이까지를 등고 간격으로 나눈 값(반올림, 최소 1장)입니다.
- 건물은 외곽선을 따라 땅이 가장 낮은 곳의 층에 섭니다. 그 위 층들은 건물 바닥 모양만큼 도려내서 건물이 평평하게 앉습니다. 도려낸 자리에는 다른 조각이 배열될 수 있습니다.
- 앉는 층에는 건물 바닥선을 새깁니다. 조각 이름은 `B07.1`, `B07.2`…(7번 건물, 아래에서 1장째)이고, 지붕 장만 이름이 보입니다.
- **높이를 모르는 건물은 높이를 지어내지 않고** 바닥선만 보이는 면에 새깁니다(조립도 점선).
- 층수 × 층고로 추정한 높이는 조각 목록 `estimated`와 조립도 베이지색으로 표시합니다. 브이월드 API 층수(화면용)는 파일에 쓰지 않습니다. 오프라인 추정이 있으면 그것을 쓰고, 없으면 바닥선만 새깁니다.

## 계단식 지형 (3D)

`terrace_view(terrain, interval_m)`(`sida/model_base/terraces.py`)는 땅을 등고 간격마다 한 장씩 쌓은 계단식 3D로 만듭니다. 각 층의 윗면이 그 등고 높이(해발)에 있고 두께는 간격 하나라서, 층의 가장자리가 그 높이의 등고선과 같습니다. 0층은 모형 전체 판입니다.

- **간격은 사용자가 정합니다.** 미터로 바로 넣거나, 판 두께 × 축척(`contour_interval`, 3 mm·1:500 → 1.5 m)으로 구합니다. 레이저 조각도 같은 간격으로 나뉩니다.
- 결과는 제도판 좌표(대지 가운데 기준 m, z는 대지 가운데 지면 0)의 구멍 있는 폴리곤이라 화면에서 층마다 밀어 올리면(extrude) 됩니다. `buildings=`를 주면 건물도 자른 모형과 같은 층에, 같은 장 수 높이로 세워 줍니다.
- 화면 연결은 아직입니다. 제도판의 three.js 묶음에는 `ExtrudeGeometry`가 없어 윗면(`ShapeGeometry`)과 옆면을 따로 만듭니다.

## 실제 지형 연결

`terrain_from_grid`(`sida/model_base/terrain.py`)가 제도판의 대지 주변 지형(`sida/experts/site/context3d.py`의 `ground()`: 대지 가운데 기준 ±half m 정사각 격자, 2 m 간격, 대지 가운데 높이 0)을 받아 모형에 담을 `--area`만큼 대지 가운데를 중심으로 잘라 냅니다.

- 높이는 `ground_elev`를 더해 해발로 둡니다. 그래서 등고 층이 해발 1.5 m, 3 m … 같은 고른 높이에서 나뉩니다.
- 대지 경계와 땅의 종류(`road`, `sidewalk`, `water`)는 같은 m 좌표의 폴리곤으로 받습니다. 그 밖의 종류는 버립니다.
- 격자가 모형 범위보다 작으면 지어내지 않고 오류를 냅니다.
- 화면·API 연결은 주변 3D(`feat/site-context-3d`)가 main에 들어간 뒤 대지 영역(`sida/experts/site/`)에서 합니다. 지형 결과물은 국외 서버에 올리지 않습니다.

```bash
python scripts/model_base_terrain.py --sheet 600x400 --thickness 3 --scale 500 --area 240x180 --out output/model_base
```

| 옵션 | 뜻 | 기본 |
|---|---|---|
| `--sheet` | 재료 판 크기 mm (가로x세로) | 600x400 |
| `--thickness` | 재료 두께 mm. 등고 간격 = 두께 × 축척 / 1000 m (3 mm, 1:500 → 1.5 m) | 3 |
| `--scale` | 모형 축척 1:N | 500 |
| `--area` | 모형에 담을 땅 m (동서x남북) | 240x180 |
| `--hollow` | 다음 층에 가려지는 속을 비우고 남길 테두리 폭 mm. 0이면 속이 찬 층 | 0 |
| `--colors` | 레이저 색, 예: `engrave=#0000FF,inner=#FF0000,outer=#00A000` | 왼쪽 예 |
| `--gap`, `--margin` | 조각 사이 간격, 판 가장자리 여백 mm | 2, 5 |
| `--rotations`, `--res` | 조각마다 시험할 방향 수, 배열 격자 mm(작을수록 빽빽하고 느림) | 8, 1 |

## 나오는 파일

- `sheet-N.svg`, `sheet-N.dxf`: 레이저용, mm. 선이 세 가지이고 레이저는 이 순서로 돌립니다: **새기기(파랑)** → **내부 커팅(빨강)**: 구멍과 구멍 속 조각의 외곽, 안쪽 것부터 → **외부 커팅(초록)**: 바깥 외곽. DXF 레이어는 `ENGRAVE`, `CUT_INNER`, `CUT_OUTER`, SVG 그룹도 같은 순서입니다. 레이저실 색 규칙이 다르면 `--colors`로 바꿉니다.
- `sheet-N-guide.svg`: 사람이 보는 같은 판. 높이별 색, 큰 조각 이름.
- `assembly.svg`: 완성 모형을 위에서 본 조립도. 조각마다 `이름·판 번호`(예: `1-05A·3`), 모듈 경계와 번호, 대지 경계(빨간 점선), 방위, 축척 막대.
- `pieces.csv`: 조각 목록(이름, 종류(땅·건물), 모듈, 층, 등고 높이, 판, 면적, 이름이 가려지는 면에 새겨졌는지, 추정 높이인지).

## 조각을 알아보는 법

- 이름 `03B`: 3층(아래에서 네 번째 판), B 조각(같은 층에서 북쪽부터, 같은 줄이면 서쪽부터). 모듈로 나뉜 모형은 앞에 모듈 번호가 붙음(`1-03B`).
- 조각마다 이름과 **북쪽 화살표**가 새겨집니다. 이름은 되도록 다음 층에 가려지는 면에 새겨 완성 모형에는 보이지 않습니다.
- **다음 층이 놓일 선**과, 보이는 면에 걸친 **대지 경계**가 새겨져 있어 맞춰 붙이기 쉽습니다.
- 지형에 땅의 종류가 있으면 **도로·인도·수계 경계**도 보이는 면에만 새깁니다. 맞닿은 도로·인도의 경계는 한 번만, 대지 경계와 겹치는 선은 대지 경계로 한 번만 새깁니다. 조립도에는 회색(도로)·베이지(인도)·파랑(수계)으로 칠합니다.

## 판보다 큰 모형: 모듈로 나누기

모형이 판보다 크면 **모형 전체를 반으로**(그래도 크면 4등분, 6등분…) 먼저 나눕니다. 나누는 선은 모형을 가로지르는 직선이고 모든 층이 같은 선에서 나뉘어, 판 두 장으로 만든 스터디 모형처럼 모듈을 따로 쌓아 붙입니다. 긴 변을 먼저 자르고, 모듈은 되도록 정사각형에 가깝게 합니다. 모듈이 판에 들어가므로 층 조각은 더 나누지 않습니다.

- 조각 이름 앞에 모듈 번호가 붙습니다: `1-03B` = 1번 모듈 3층 B 조각. 모듈 번호는 북서쪽부터 셉니다.
- 조립도에 모듈 경계(굵은 선)와 번호가 나옵니다.

## 구멍 속 조각과 자르는 순서

레이저는 내부 커팅 → 외부 커팅 두 번으로 자르므로, 구멍에는 **구멍 없는 조각만 한 겹** 들어갑니다(구멍 있는 조각은 다른 조각의 구멍에 들어가지 않음). 구멍은 땅이 움푹한 곳이나 `--hollow`로 속을 비운 층에서 생깁니다.

## 배열 방식

조각을 격자로 바꿔, 외곽이 차지하는 크기가 큰 조각부터 여러 방향으로 돌려 가며 판의 가장 아래·왼쪽 빈자리에 넣습니다(모든 자리를 FFT 상관으로 한 번에 검사).

# Geumjeong Station Project Brief

## Project Type
Transit architecture / graduation studio

## Site
Geumjeong Station, Gunpo, South Korea

## Core Problem
The station connects movement but also reinforces disconnection.

## Site Issues
- Railway infrastructure divides the urban fabric.
- Station bodies are separated.
- The nearby stream condition is hidden or disconnected.
- Road systems and railway systems create fragmented pedestrian movement.
- Transfer movement is fast and functional.
- Public staying space is weak.

## Design Intention
Redefine the transfer station as a public spatial system that supports both fast movement and slow pause.

## Main Layers
- Fast transfer layer
- Slow walking layer
- Extra public space
- Sectional crossing
- Visual connection across infrastructure

## Current Design Direction
The project uses layered circulation, section-based spatial contrast, and crossing points as public extra spaces.

## Representation Focus
The project should be explained through layer diagrams, circulation diagrams, and sections rather than long narrative text.

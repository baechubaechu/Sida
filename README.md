<p align="center"><b>건축 학생을 위한 초기 설계 AI 에이전트</b></p>

---

**시다**는 건축 현장에서 조수를 부르는 말입니다. Sida도 건물을 대신 설계하지 않습니다. 대지 주소 하나에서 출발해 대지를 읽고, 조건을 정리하고, 안을 비교하고, 크리틱을 받는 초기 설계 과정을 옆에서 돕습니다.

## 무엇을 하나요

- **대지 사실 조회** — 주소를 넣으면 정부 자료로 필지, 용도지역, 법정 건폐율·용적률, 도시계획 도로, 기존 건축물을 가져옵니다. 지자체 조례의 해당 조문은 원문 그대로 모두 보여 줍니다.
- **전문가 팀** — 대지 분석가, 프로그램 분석가, 법규 검토자, 선례 연구자, 설계 비평가, 표현 계획자, 발표 편집자가 각자의 관점으로 검토합니다. Conductor가 이들을 불러 조건, 서로 어긋나는 점, 지금 정할 것을 정리합니다.
- **제도판** — 대지 도면 위에 스케치, 메모, 사진, 매스안을 올려 놓고 고른 것을 AI에게 물어봅니다. 중요한 생각은 아이디어 보드에 남겨 둡니다.
- **주변 3D와 모형** — 대지 주변 건물과 지형을 3D로 보고, 레이저 커팅용 대지 모형 판(DXF·PDF·SVG)을 만듭니다.
- **내보내기** — 제도판의 대지와 매스안을 CAD(DXF)나 Rhino(3dm) 파일로 가져갑니다.

## 원칙

1. **숫자는 지어내지 않습니다.** 대지 수치는 정부 자료에서, 조례 수치는 정해진 규칙으로만 읽습니다. 확인하지 못한 항목은 "미확인"으로 남깁니다.
2. **근거를 같이 보여 줍니다.** 수치 옆에는 그 수치를 읽은 원문 줄과 조문 번호가 붙습니다.
3. **설계는 설계자가 합니다.** AI의 해석은 설계자가 검토하고 고르는 재료이고, 정답으로 제도판에 올라가지 않습니다.

## 시작하기

**필요한 것:** Windows PC, [Python 3.10 이상](https://www.python.org/downloads/) (설치할 때 "Add python.exe to PATH" 체크)

1. 이 저장소를 내려받습니다.
2. `run.bat`을 더블클릭합니다. 처음 한 번은 필요한 것을 설치하느라 시간이 걸립니다.
3. 브라우저가 열리면 **설정**에서 AI 연결 방법을 고릅니다.
   - **ChatGPT 로그인** — 쓰고 있는 ChatGPT 구독으로 연결합니다.
   - **OpenRouter** — API 키를 넣습니다.
   - **로컬(Ollama)** — 키와 비용 없이 내 PC의 GPU로 돌립니다(VRAM 8GB 이상).
4. 대지 조회와 법령 검색을 쓰려면 설정에서 **Sida 키**를 요청합니다. 팀이 확인하면 키가 자동으로 들어옵니다.

프로젝트는 서버가 아니라 내 PC의 사용자 폴더(`Sida\projects`)에 저장됩니다. macOS·Linux에서 실행하는 법은 [`docs/dev-setup.md`](docs/dev-setup.md)에 있습니다.

## 한계

- 아직 시험판(v0.2)입니다. 화면과 기능이 자주 바뀝니다.
- 법규 검토와 선례는 확인할 목록을 주는 것이지 확정된 사실이 아닙니다. 최종 판단은 설계자가 원문으로 확인합니다.
- 결과의 질은 브리프와 연결한 AI 모델에 따라 달라집니다.
